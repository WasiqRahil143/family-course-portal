# Project instructions

Before changing this repository, read `PROJECT_CONTEXT.md`.

For every meaningful change to functionality, product decisions, integrations, architecture, limitations, security, data model, deployment, or roadmap:

1. Update the relevant section of `PROJECT_CONTEXT.md`.
2. Update its `Last updated` date when necessary.
3. Add a concise entry to its change log.
4. Include the context update in the same commit as the implementation.

Do not modify or connect any GitHub, Netlify, Supabase, email, or other project except the resources explicitly documented for this portal. Ask before creating a new external resource when the exact target is not already documented.

Never describe a frontend-only interaction as persistent or production-ready. Keep `PROJECT_CONTEXT.md` honest about what is implemented, connected, tested, and still planned.
